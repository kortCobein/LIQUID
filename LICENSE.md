# Licencia SOLID del Equipo LIQUID

Versión académica 1.0

Este repositorio existe con fines educativos y de evaluación académica.

Se permite al equipo estudiar, modificar, ejecutar y extender este proyecto durante el desarrollo del Sprint y para fines de aprendizaje.

## Cláusula SOLID

Toda persona que toque este código acepta, de manera totalmente seria y nada sospechosa, intentar recordar que:

- **S**: una clase no debería hacer absolutamente de todo.
- **O**: extender es mejor que romper lo que ya funciona.
- **L**: si una implementación cumple un contrato, debe poder sustituir a otra sin provocar el apocalipsis.
- **I**: una interfaz pequeña suele ser más fácil de explicar que una interfaz monstruosa.
- **D**: depender de abstracciones evita terminar escribiendo `new RepositorioLoQueSea()` por todo el proyecto.

## Cláusula de supervivencia académica

Si un integrante puede explicar qué hace una clase, por qué existe y de qué depende, se considera que el código va por buen camino.

Si nadie puede explicarlo sin abrir cinco pestañas y pedir auxilio, probablemente toca simplificar.
